# Ragnavik Shared Pack

Shared client-and-server dependencies and synchronized configuration for Ragnavik.

This package is installed by both the Ragnavik Client Pack and Ragnavik Server Pack. It must not contain client-only UI mods or dedicated-server-only runtime mods.
DedicatedServer 1.0.3 is included as a testing-phase dependency. It moves world
simulation ownership to the dedicated server and must be installed on both sides.
Its compatibility and server cost must be verified before production use.
